# NoC Development Project

This repository contains the development of a Network-on-Chip (NoC).
The project is divided into four main parts:

1.  **Architecture & Trace**: Architecture definitions, trace format specifications, and analysis tools.
2.  **C Model**: Functional NoC simulator in C++.
3.  **TLM Model**: SystemC Transaction Level Modeling of the NoC.
4.  **RTL**: Verilog implementation of the NoC.
