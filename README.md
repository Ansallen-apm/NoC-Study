# NoC Development Project (片上網路開發專案)

This repository contains the development of a Network-on-Chip (NoC).
The project is divided into four main parts:
(此儲存庫包含片上網路 (NoC) 的開發。專案分為四個主要部分：)

1.  **Architecture & Trace (架構與 Trace)**: Architecture definitions, trace format specifications, and analysis tools. (架構定義、trace 格式規範與分析工具。)
2.  **C Model**: Functional NoC simulator in C++. (C++ 功能性 NoC 模擬器。)
3.  **TLM Model**: SystemC Transaction Level Modeling of the NoC. (NoC 的 SystemC 交易層級建模。)
4.  **RTL**: Verilog implementation of the NoC. (NoC 的 Verilog 實作。)
